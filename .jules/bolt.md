## 2024-11-08 - Use Framer Motion hooks for continuous interactions
**Learning:** Using React's `useState` for continuous user interactions like `onMouseMove` (e.g., in `MagneticButton`) triggers a React re-render on every frame/movement, which is a performance bottleneck. Framer Motion provides `useMotionValue` and `useSpring` which can be bound directly to style properties. This updates the DOM directly without triggering the React render cycle, significantly improving performance for animations.
**Action:** Prefer Framer Motion's `useMotionValue` and `useSpring` over `useState` for continuous interactions (like mouse movements or scrolling) to bypass the React render cycle and avoid unnecessary re-renders. Bind the resulting values directly to the `style` prop instead of `animate`.
