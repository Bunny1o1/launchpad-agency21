## 2024-05-23 - Framer Motion continuous interaction performance pattern
**Learning:** Continuous user interactions like `mousemove` and `scroll` bound to React's `useState` for animation trigger severe render cycle bottlenecks. Using Framer Motion's `animate` prop along with `useState` forces React to reconcile the entire component tree on every single pixel of movement, causing noticeable jank and high CPU usage.
**Action:** Always prefer Framer Motion's `useMotionValue` and `useSpring` hooks for continuous interactions. Bind these directly to the `style` prop (e.g., `style={{ x: springX, y: springY }}`). This pattern completely bypasses the React render cycle, mapping the values directly to the DOM node styles for optimal 60fps performance without unnecessary re-renders.
